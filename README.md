# 🎙️ Voice Cloner UI

A simple **Gradio-based web app** that uses [Coqui TTS](https://github.com/coqui-ai/TTS) to clone a reference voice and generate speech from input text.  
Upload a `.wav` file, type your text, and hear it spoken in the cloned voice — all in your browser!

---

## 🚀 Features

- **Voice Cloning** – Generate speech in the style of your uploaded reference voice.
- **Text-to-Speech** – Input any text and get natural-sounding speech.
- **Interactive UI** – Built with Gradio, runs locally with zero setup.
- **Multilingual Support** – Works with the `tts_models/multilingual/multi-dataset/your_tts` model.
